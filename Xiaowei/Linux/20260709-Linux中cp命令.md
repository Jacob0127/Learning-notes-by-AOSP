# cp命令的作用

在Linux中，cp命令使用来复制的，可以理解为copy。核心功能是复制文件和目录。

# 基本语法

```bash
cp [选项] 源文件/目录 目标路径
```

- **源文件/目录**：你要复制的内容。
- **目标路径**：你要复制到哪里去（可以是一个目录，也可以是一个新的文件名）。

# 常用参数

## 递归相关（针对目录）

| 参数       | 作用                                                         |
| ---------- | ------------------------------------------------------------ |
| `-r`或`-R` | **递归复制**。**必须加**，否则无法复制文件夹。               |
| `-a`       | **归档模式**。它是 `-dR --preserve=all` 的快捷方式。即：递归复制（`-R`） + 保留链接（`-d`） + 保留所有属性（权限、时间戳、所有者等）。**常用于备份**。 |

## 覆盖与交互（安全相关）

| 参数     | 作用                                                         |
| :------- | :----------------------------------------------------------- |
| **`-i`** | **交互式**。如果目标文件已存在，会询问你是否覆盖（输入 `y` 或 `n`）。很多系统默认将此设置为别名（即输入 `cp` 等同于 `cp -i`）。 |
| **`-f`** | **强制覆盖**。不询问，直接覆盖。如果目标文件无法写入（例如只读），会先删除再创建。 |
| **`-n`** | **不覆盖**。如果目标文件已存在，则不做任何操作。             |
| **`-u`** | **更新模式**。只有当源文件比目标文件新，或目标文件不存在时，才执行复制。常用于增量备份。 |

## 行为细节与路径控制

| 参数     | 作用                                                         |
| :------- | :----------------------------------------------------------- |
| **`-T`** | **无目标目录（No-target-directory）**）。强制将目标视为**普通文件**。如果目标是一个存在的目录，`cp` 会报错，而不是把源复制进该目录。用于防止误操作。 |
| **`-t`** | **目标目录（Target directory）**。将参数顺序反过来，即 `cp -t 目标目录 源文件1 源文件2...`。常用于结合 `find` 或 `xargs`。 |
| **`-v`** | **详细输出**。显示正在复制的文件列表（如 `‘source.txt’ -> ‘dest.txt’`），用于调试。 |
| **`-p`** | **保留属性**。保留文件的修改时间、访问时间、权限。`-a` 包含此功能。 |
| **`-l`** | **硬链接**。不复制数据，而是创建硬链接。                     |
| **`-s`** | **符号链接**。创建符号链接（快捷方式），而不是复制物理文件。 |
