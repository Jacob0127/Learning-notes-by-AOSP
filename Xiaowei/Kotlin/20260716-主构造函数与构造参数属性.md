# 主构造函数与构造参数属性

## 概念说明

Kotlin 的类有一个**主构造函数**（primary constructor），是类头的一部分，通过 `constructor` 关键字声明。主构造函数的参数可以直接用 `val`/`var` 声明为类的属性，这比 Java 的写法简洁得多。

如果构造函数需要加注解或可见性修饰符，必须显式写 `constructor` 关键字。

## 代码示例

```kotlin
class ModesTileMapper
@Inject
constructor(@ShadeDisplayAware private val resources: Resources, val theme: Resources.Theme)
    : QSTileDataToStateMapper<ModesTileModel> {
    // ...
}
```

### 对比 Java 写法

```java
// Java 写法：需要手动写字段、构造函数、赋值
public class ModesTileMapper implements QSTileDataToStateMapper<ModesTileModel> {
    private final Resources resources;
    private final Resources.Theme theme;

    @Inject
    public ModesTileMapper(@ShadeDisplayAware Resources resources, Resources.Theme theme) {
        this.resources = resources;
        this.theme = theme;
    }
}
```

```kotlin
// Kotlin 写法：一行搞定，参数即属性
class ModesTileMapper @Inject constructor(
    @ShadeDisplayAware private val resources: Resources,
    val theme: Resources.Theme
) : QSTileDataToStateMapper<ModesTileModel>
```

## 关键要点

- 主构造函数在类头声明，紧跟类名
- 参数加 `val` → 只读属性（相当于 Java 的 `final` 字段 + getter）
- 参数加 `var` → 可变属性（相当于 Java 的字段 + getter/setter）
- 参数不加 `val`/`var` → 仅在 init 块和属性初始化中可用，不是类属性
- 有注解或可见性修饰符时，必须显式写 `constructor` 关键字
- 继承父类/实现接口用 `:` 后跟父类名，和 Java 的 `extends`/`implements` 对应
