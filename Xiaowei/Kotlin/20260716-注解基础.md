# 概念说明

**注解（Annotation）** 是附加在代码元素（类、函数、属性、参数等）上的元数据标记。注解本身不执行逻辑，而是给编译器或框架提供额外信息。

Kotlin 中注解以 `@` 开头，可以放在代码元素的上方。

# 注解的本质：annotation class

Kotlin 中所有注解本质都是一个 `annotation class`。以 `@Inject` 为例，它的定义类似：

```kotlin
// javax.inject.Inject 的定义（简化）
@Target(AnnotationTarget.CONSTRUCTOR, AnnotationTarget.FIELD, AnnotationTarget.METHOD)
@Retention(AnnotationRetention.RUNTIME)
annotation class Inject
```

而 `@ShadeDisplayAware` 作为限定符，定义类似：

```kotlin
@Qualifier                               // ← 它本身也是一个注解（元注解）
@Target(AnnotationTarget.VALUE_PARAMETER)
@Retention(AnnotationRetention.RUNTIME)
annotation class ShadeDisplayAware
```

## 关键概念拆解

| 概念               | 说明                                                         | 代码中的例子                                           |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------ |
| `annotation class` | 定义注解的关键字，类似 Java 的 `@interface`                  | `annotation class Inject`                              |
| `@Target`          | **元注解**，指定这个注解能放在哪些位置（构造函数、属性、参数等） | `@Inject` 的 Target 包含 CONSTRUCTOR                   |
| `@Retention`       | **元注解**，指定注解保留到什么阶段（源码/字节码/运行时）     | `@Inject` 保留到 RUNTIME，框架在运行时反射读取         |
| `@Qualifier`       | Dagger 的元注解，标记"这是一个限定符注解"                    | `@ShadeDisplayAware` 上有 `@Qualifier`                 |
| 注解参数           | 注解可以带参数，用 `val` 声明                                | `annotation class ReplaceWith(val expression: String)` |

## Kotlin 常见内置注解

| 注解            | 作用                                            | 示例                                                         |
| --------------- | ----------------------------------------------- | ------------------------------------------------------------ |
| `@Target`       | 指定注解可用位置                                | `@Target(AnnotationTarget.CLASS, AnnotationTarget.FUNCTION)` |
| `@Retention`    | 指定注解保留阶段                                | `@Retention(AnnotationRetention.RUNTIME)`                    |
| `@Deprecated`   | 标记弃用，编译器会警告                          | `@Deprecated("use newFunc()", ReplaceWith("newFunc()"))`     |
| `@JvmStatic`    | 让 Kotlin 函数在 JVM 层面生成真正的 static 方法 | `companion object` 中的 `@JvmStatic fun foo()`               |
| `@JvmField`     | 暴露属性为 Java 字段（不生成 getter/setter）    | `@JvmField val count = 0`                                    |
| `@JvmOverloads` | 为有默认参数的函数生成多个重载                  | `@JvmOverloads fun f(a: Int, b: Int = 0)`                    |
| `@Repeatable`   | 允许同一位置重复使用同一注解                    | `@Repeatable annotation class Tag(val name: String)`         |

## @Target 可选值

```kotlin
AnnotationTarget.CLASS        // 类
AnnotationTarget.FUNCTION     // 函数
AnnotationTarget.PROPERTY     // 属性
AnnotationTarget.FIELD        // 幕后字段
AnnotationTarget.VALUE_PARAMETER  // 参数（函数参数/构造函数参数）
AnnotationTarget.CONSTRUCTOR  // 构造函数
AnnotationTarget.TYPE         // 类型（如泛型参数位置）
AnnotationTarget.EXPRESSION   // 表达式
AnnotationTarget.FILE         // 文件
```

## @Retention 三个级别

```kotlin
AnnotationRetention.SOURCE    // 只在源码中存在，编译后丢弃（如 @Override 在 Java 中）
AnnotationRetention.BINARY    // 编译到字节码中，但运行时反射读不到
AnnotationRetention.RUNTIME   // 编译到字节码中，运行时可通过反射读取（框架常用）
```

> `@Inject` 和 `@ShadeDisplayAware` 都是 RUNTIME 级别，因为 Dagger 需要在运行时通过反射读取它们来组装依赖。

## 关键要点

- 注解 = 代码上的元数据标记，以 `@` 开头，本身不执行逻辑
- 定义注解用 `annotation class`，用 `@Target` 和 `@Retention` 这两个**元注解**控制其行为
- Kotlin 中如果构造函数需要加注解，必须显式写 `constructor` 关键字
- `@Inject` 是 JSR-330 标准注解，不是 Kotlin 语言内置的，需要依赖 `javax.inject` 包
- `@ShadeDisplayAware` 是项目自定义的限定符注解，用 `@Qualifier` 元注解标记
