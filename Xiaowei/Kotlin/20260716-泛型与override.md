# 实现泛型接口与 override 重写

## 概念说明

Kotlin 中实现接口用 `:` 号（对应 Java 的 `implements`），继承类也用 `:` 号（对应 `extends`）。

当一个接口是**泛型接口**时，实现时需要指定具体的类型参数。

重写父类/接口的方法用 `override` 关键字修饰（Kotlin 中 `override` 是必须的，不像 Java 可以省略）。

## 代码示例

```kotlin
// 接口定义（泛型接口，T 是类型参数）
interface QSTileDataToStateMapper<T> {
    fun map(config: QSTileConfig, data: T): QSTileState
}

// 实现类：指定 T = ModesTileModel
class ModesTileMapper @Inject constructor(...)
    : QSTileDataToStateMapper<ModesTileModel> {

    override fun map(config: QSTileConfig, data: ModesTileModel): QSTileState {
        // data 的类型是 ModesTileModel（不是泛型 T）
        // ...
    }
}
```

### 逐行解析

| 代码 | 含义 |
|------|------|
| `: QSTileDataToStateMapper<ModesTileModel>` | 实现接口，指定泛型参数为 `ModesTileModel` |
| `override fun map(...)` | 重写接口的方法，`override` 关键字必须写 |
| `data: ModesTileModel` | 方法的 data 参数类型与接口定义中的 `T` 对应，被替换为 `ModesTileModel` |
| `: QSTileState` | 返回值类型 |

## 关键要点

- Kotlin 用 `:` 同时表示继承和实现接口，多个用 `,` 分隔
- 实现泛型接口时，在尖括号中指定具体类型 `<ModesTileModel>`
- `override` 是**强制必须**的关键字，不像 Java 可选
- 如果方法参数或返回值涉及泛型 `T`，实现时 `T` 会被替换为实际类型
- `override` 的方法默认是 `open` 的（可被继续重写），加 `final` 可阻止
