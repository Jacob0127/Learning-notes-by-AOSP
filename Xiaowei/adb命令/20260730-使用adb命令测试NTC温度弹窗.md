### 修改后行为

温度值单位均为 **0.1°C**。

| 电池温度 | 内核阈值 (DTS)                    | 框架阈值 (Java) | 行为                                                  |
| -------- | --------------------------------- | --------------- | ----------------------------------------------------- |
| >= 60°C  | `cm-battery-hot=550` (停充)       | `>= 600`        | 停充 + 弹窗 + 10 秒倒计时 → **自动关机**              |
| >= 55°C  | `cm-battery-hot=550` (停充)       | `>= 550`        | **停充** + 高温警告弹窗，不关机                       |
| <= -5°C  | `cm-battery-cold=50` (停充，负值) | `<= -50`        | **停充** + 低温警告弹窗，不关机                       |
| <= -25°C | 已停充（-5°C 以下即停）           | `<= -250`       | 停充 + 弹窗 + 10 秒倒计时 → **自动关机** (NTC 超低温) |

> **注意**：停充由内核 charger manager 的 `cm-battery-cold` / `cm-battery-hot` 控制，弹窗和关机由框架 PowerUI / BatteryService 控制。两者是独立路径，最终效果叠加为表中行为。

## 架构说明：弹窗与停充是两条独立路径

```
电池 NTC 温度
     │
     ├─► fuel gauge 驱动 (/sys/class/power_supply/battery/temp)
     │       │
     │       ├─► Health HAL (15s 轮询) → BatteryService → PowerUI
     │       │       │                                    │
     │       │       │                          弹窗 / 关机倒计时
     │       │       │
     │       │       └─► BatteryService.shutdownIfOverTempLocked()
     │       │                │
     │       │          10s 后执行关机
     │       │
     │       └─► charger manager (uevent / 中断触发)
     │               │
     │          cm-battery-cold / cm-battery-hot 判断
     │               │
     │          emergency_stop → 停充
     │
     ▼
  真机上温度缓慢变化，charger manager 响应是毫秒级的，
  弹窗出现时充电早已停止。测试时用 echo 瞬间跳变才会
  看到时序差，这不是 bug。
```

## adb 模拟验证命令

> **框架层弹窗/关机验证**：用 `dumpsys battery set temp`  
> **内核层停充验证**：用 `echo <值> > /sys/class/power_supply/battery/temp`  
> 两条路径独立，建议分开测试。

### 前置操作

```bash
# 切断充电状态，避免充电逻辑干扰
adb shell dumpsys battery unplug
adb shell dumpsys battery set status discharging
```

### 一、框架层验证 (弹窗 + 关机倒计时)

```bash
# 高温警告弹窗 (55°C, 不关机)
adb shell dumpsys battery set temp 550

# 高温关机倒计时 (60°C, 10秒后自动关机)
adb shell dumpsys battery set temp 600

# 高温关机倒计时 (65°C)
adb shell dumpsys battery set temp 650

# 低温警告弹窗 (-5°C, 不关机)
adb shell dumpsys battery set temp -50

# 低温关机倒计时 (-25°C, 10秒后自动关机)
adb shell dumpsys battery set temp -250

# 恢复正常温度 (25°C)
adb shell dumpsys battery set temp 250

# 停止模拟，恢复真实电池状态
adb shell dumpsys battery reset
```

| 模拟值 | 实际温度 | 弹窗类型   | 10秒倒计时 | 自动关机 |
| ------ | -------- | ---------- | ---------- | -------- |
| 550    | 55°C     | 高温警告   | 无         | 否       |
| 600    | 60°C     | 关机倒计时 | 有         | **是**   |
| 650    | 65°C     | 关机倒计时 | 有         | **是**   |
| -50    | -5°C     | 低温警告   | 无         | 否       |
| -250   | -25°C    | 关机倒计时 | 有         | **是**   |
| 250    | 25°C     | 无         | 无         | 否       |

### 二、内核层验证 (停充)

```bash
# 确认当前充电状态
adb shell cat /sys/class/power_supply/battery/status     # 应为 Charging (需先插充电器)
adb shell cat /sys/class/power_supply/battery/temp        # 当前温度

# --- 低温停充测试 ---
# 模拟 -6°C (阈值 -5°C = -50)
adb shell "echo -60 > /sys/class/power_supply/battery/temp"
sleep 2
adb shell cat /sys/class/power_supply/battery/status     # 应变为 Discharging / Not charging

# --- 高温停充测试 ---
# 先恢复正常温度 (解除低温停充)
adb shell "echo 250 > /sys/class/power_supply/battery/temp"
sleep 2
# 模拟 56°C (阈值 55°C = 550)
adb shell "echo 560 > /sys/class/power_supply/battery/temp"
sleep 2
adb shell cat /sys/class/power_supply/battery/status     # 应变为 Discharging / Not charging

# --- 恢复 ---
adb shell "echo 250 > /sys/class/power_supply/battery/temp"
```

| 写入值 | 实际温度 | 预期结果                 |
| ------ | -------- | ------------------------ |
| -60    | -6°C     | status = Discharging     |
| 560    | 56°C     | status = Discharging     |
| 250    | 25°C     | status = Charging (恢复) |

### 三、收尾

```bash
adb shell dumpsys battery reset
adb shell "echo 250 > /sys/class/power_supply/battery/temp"
```
