# Android 暗码（Secret Code）添加

## 1. 什么是暗码

暗码（Secret Code）是指用户在拨号盘输入 `*#*#<code>#*#*` 后，系统自动跳转到某个功能页面的机制。例如输入 `*#*#83781#*#*` 进入工程师模式。

Android 通过 `android.provider.Telephony.SECRET_CODE` 广播实现这一功能。当用户在拨号盘输入暗码后，系统会发出该广播，携带 `android_secret_code` scheme 的 data URI，其中 `host` 就是用户输入的暗码数字。

---

## 2. 哪种暗码放哪个 App

本项目中两个 App 都可以注册暗码，选择依据：

| App                 | 路径                                                      | 适用场景                                                     |
| ------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| **EngineerMode**    | `SYS/vendor/sprd/platform/packages/apps/EngineerMode/`    | 需要自定义 Java 逻辑处理页面（如手写 IMEI），或直接复用已有的工程师模式页面 |
| **ValidationTools** | `SYS/vendor/sprd/platform/packages/apps/ValidationTools/` | 暗码指向的功能已在 ValidationTools 中有现成页面，只需声明 intent-filter 即可，不需要写任何 Java 代码 |

---

## 3. 方式一：在 EngineerMode 中添加暗码（完整流程）

以 **暗码 88 进入手写 IMEI 页面** 为例，这是最完整的新增暗码场景。

### 3.1 修改文件清单

| 文件                   | 修改内容                                                     |
| ---------------------- | ------------------------------------------------------------ |
| `AndroidManifest.xml`  | ①注册新 Activity（如需新页面）②在 EMStartReceiver 中声明 intent-filter |
| `EMStartReceiver.java` | 添加暗码到目标 Activity 的路由分支                           |
| 新 Activity `.java`    | 编写目标页面的业务逻辑（如不需要新页面可跳过）               |
| 新 layout `.xml`       | 编写目标页面的布局（如不需要新页面可跳过）                   |
| `strings.xml`          | 添加页面所需的字符串资源                                     |

所有文件均在 `SYS/vendor/sprd/platform/packages/apps/EngineerMode/` 目录下。

### 3.2 第一步：AndroidManifest.xml

#### 3.2.1 注册目标 Activity（如果需要新页面）

在 `<application>` 标签内添加：

```xml
<activity
    android:name="com.sprd.engineermode.SetIMEI"
    android:exported="true"
    android:label="Info"
    android:screenOrientation="portrait"
    android:theme="@style/EngAppActivityTheme">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.DEFAULT" />
    </intent-filter>
</activity>
```

| 属性                        | 说明                                              |
| --------------------------- | ------------------------------------------------- |
| `android:name`              | Activity 完整类名                                 |
| `android:exported="true"`   | 必须设为 true，因为暗码广播来自拨号盘，跨进程调用 |
| `android:screenOrientation` | 屏幕方向，一般 `portrait`（竖屏）                 |
| `android:theme`             | 沿用工程师模式的统一主题                          |

#### 3.2.2 在 EMStartReceiver 中声明 intent-filter

在 `<receiver android:name="EMStartReceiver">` 标签内添加：

```xml
<intent-filter>
    <action android:name="android.provider.Telephony.SECRET_CODE" />
    <data
        android:host="88"
        android:scheme="android_secret_code" />
</intent-filter>
```

**关键**：

- `action` 必须是 `android.provider.Telephony.SECRET_CODE`
- `scheme` 必须是 `android_secret_code`
- `host` 就是暗码数字（如 `88`、`8615`）
- 每个 intent-filter 可以包含多个 `<data>` 元素（对应多个暗码），也可以每个暗码独立一个 intent-filter，效果相同

### 3.3 第二步：EMStartReceiver.java 添加路由

```java
} else if("88".equals(host)){
    i.setClass(context, SetIMEI.class);
    context.startActivity(i);
}
```

**模式很固定**：

1. 通过 `uri.getHost()` 获取暗码
2. `i.setClass(context, TargetActivity.class)` 指定目标 Activity
3. `context.startActivity(i)` 启动目标页面

**如果复用已有页面**（如暗码 8615 复用 SensorsIDActivity），只需要新增一行路由：

```java
} else if ("8615".equals(host)){
    i.setClass(context, SensorsIDActivity.class);
    context.startActivity(i);
}
```

### 3.4 第三步：创建目标 Activity 和布局文件（如需新页面）

这是暗码 88 的 SetIMEI.java 完整示例骨架：

```java
package com.sprd.engineermode;

import android.app.Activity;
import android.os.Bundle;
import android.view.View;
import android.view.View.OnClickListener;

public class SetIMEI extends Activity implements OnClickListener {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.setimei);   // 关联布局文件
        // 初始化控件和业务逻辑...
    }

    @Override
    public void onClick(View v) {
        // 处理按钮点击...
    }
}
```

布局文件放在 `res/layout/` 目录下，如 `setimei.xml`。

### 3.5 第四步：添加字符串资源

在 `res/values/strings.xml` 中添加：

```xml
<string name="setimei">Set IMEI</string>
<string name="sim1">SIM1 IMEI</string>
<string name="sim2">SIM2 IMEI</string>
<string name="read_btn">Read IMEI</string>
<string name="set_btn">Set IMEI</string>
```

## 4. 方式二：在 ValidationTools 中添加暗码（仅声明）

如果暗码对应的功能页面已存在于 ValidationTools 中，**只需要在 AndroidManifest.xml 中声明 intent-filter**，不需要写任何 Java 代码。

以**暗码 66** 为例，修改 `SYS/vendor/sprd/platform/packages/apps/ValidationTools/AndroidManifest.xml`：

在对应的 `<receiver>` 标签内添加：

```xml
<!-- jzhk add secret code 66 -->
<intent-filter android:priority="1000">
    <action android:name="android.provider.Telephony.SECRET_CODE" />
    <data
        android:host="66"
        android:scheme="android_secret_code" />
</intent-filter>
```

**注意**：ValidationTools 用的是 `android:priority="1000"`（高优先级），确保它能优先于其他 receiver 处理这个暗码。

### EngineerMode vs ValidationTools 暗码声明对比

|                    | EngineerMode                  | ValidationTools                       |
| ------------------ | ----------------------------- | ------------------------------------- |
| 路由方式           | Java 代码手动路由到 Activity  | 系统自动分发到注册的 receiver         |
| 优先级             | 默认                          | `android:priority="1000"`（高优先级） |
| 是否需要改 Java    | 是（EMStartReceiver.java）    | 否                                    |
| 适用场景           | 需要自定义页面或逻辑          | 已存在功能页面                        |
| intent-filter 位置 | `EMStartReceiver` receiver 中 | 对应的 receiver 中                    |

## 5. 秘码机制原理

```
用户在拨号盘输入 *#*#88#*#*
        │
        ▼
拨号盘 APP 解析到 android_secret_code://88
        │
        ▼
系统发送广播: action = "android.provider.Telephony.SECRET_CODE"
              data  = android_secret_code://88
        │
        ▼
EMStartReceiver.onReceive() 收到广播
        │
        ▼
uri.getHost() 获取到 "88"
        │
        ▼
路由判断 → i.setClass(context, SetIMEI.class)
        │
        ▼
启动目标 Activity（SetIMEI 页面）
```

**核心点**：

- 暗码本质是 Android 的 `SECRET_CODE` 广播，不是特殊权限或 Hook
- `host` 就是暗码数字，是唯一的路由 key
- `EMStartReceiver` 是一个 BroadReceiver，集中管理所有 EngineerMode 暗码的路由逻辑
- 多个 APP 可以注册同一个暗码，Android 会弹框让用户选择，或按 priority 决定优先级

## 6. 操作检查清单

添加新的暗码时，按以下顺序操作：

### EngineerMode 方式（有自定义逻辑）

- [ ] 1. **AndroidManifest.xml**：如需新页面，添加 `<activity>` 声明
- [ ] 2. **AndroidManifest.xml**：在 `EMStartReceiver` 中添加 intent-filter
- [ ] 3. **EMStartReceiver.java**：添加 `else if("暗码".equals(host))` 路由分支
- [ ] 4. 创建目标 **Activity.java**（如需新页面）
- [ ] 5. 创建目标 **layout.xml**（如需新页面）
- [ ] 6. **strings.xml** 添加字符串资源

### ValidationTools 方式（复用已有页面）

- [ ] 1. **ValidationTools/AndroidManifest.xml**：在对应 receiver 中添加 intent-filter
- [ ] 2. 确认目标页面功能正常

### 通用验证

- [ ] 1. 编译刷机或 adb install 更新 APK
- [ ] 2. 打开拨号盘，输入 `*#*#<暗码>#*#*`
- [ ] 3. 确认自动跳转到目标页面
