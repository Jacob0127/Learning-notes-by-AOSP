根据AOSP源码中添加product的方法（详见20260617的文件），我们知道，想要添加一个产品，首先必须要的三个文件是：`device.mk`、`AndroidProducts.mk`、`BoardConfig.mk`

那么根据这些mk文件，就能找到对应的硬件信息，比如这里说的芯片

------

# 找到该项目的`device.mk`

根据编译脚本`mk`中的代码，可以看到，项目中的product list来自于路径`jzhk/mk/*.mk`。那说明，项目的`device.mk`就是这个路径下的这些`*.mk`

------

# 根据`device.mk`找到该项目的`jzhk_source_project`

然后在对应项目的`mk`文件中，可以看到`jzhk_source_project`，这个就是对应的平台信息。

------

# 根据`jzhk_source_project`找到对应的芯片平台

使用find命令在根目录中搜索这个目录，这里我用`jzhk_source_project = ums512_lwfq_1h10_go3g_Natv`这个示例搜索

```bash
android182@androidserver:/work/work1/xiaowei/1_sprd16$ find . -name "ums512_lwfq_1h10_go3g_Natv" -type d
./VND/device/sprd/sharkl5Pro/ums512_1h10_go/product/ums512_lwfq_1h10_go3g_Natv
android182@androidserver:/work/work1/xiaowei/1_sprd16$ 
```

可以看到，找到了该目录，那么很明显，对应芯片平台就是shark5Pro

------
