# `PhotoUI.java`

然后在这个文件中看到了这段代码：

```java
mShutterButton = (ShutterButton) mRootView.findViewById(R.id.shutter_button);//SPRD:fix bug 473462
```

那我们思路就很明确了，看看谁调用了`mShutterButton`这个就可以了，我们在这个`PhotoUI.java`文件中搜索它，会发现并没有哪个地方为这个`mShutterButton`按钮设置了点击事件。那点击事件监听在哪里设置的呢？所以在这里咱们思路断掉了。

怎么办呢？这个时候，有三个方向：

1. 查看`ShutterButton.java`类自身是否将监听事件定义在了内部。
2. 直接在代码中搜索为这个按钮定义的监听器，`addOnShutterButtonListener`或者`addShutterListener`都有可能
3. 可能是我们找的文件错误了，可能在别的文件中也给这个id为`shutter_button`的按钮绑定了

方向二比较难，不知道添加监听器的方法是什么，然后方向三，在搜索谁引用了这个id为`shutter_button`的按钮时，看到了有几个java类都引用了，那就先按方案三走，找到另外一个java类，`CameraAppUI.java`

# `CameraAppUI.java`


在这个类中看到了这样的代码：

```java
if (mShutterButton == null && mCameraRootView != null) {
    mShutterButton = (ShutterButton) mCameraRootView
            .findViewById(R.id.shutter_button);

```

然后我们知道这个`mShutterButton`绑定了这个按钮，那么，查找这个`mShutterButton`在哪里修改或者调用了。然后在这个代码中，看到了的代码：

```java
public void addShutterListener(
        ShutterButton.OnShutterButtonListener listener) {
    mShutterButton.addOnShutterButtonListener(listener);
}
```

这个就是给这个按钮添加了监听，追这个`addOnShutterButtonListener()`方法，可以追到`ShutterButton.java`这个类

# `ShutterButton.java`

在这个类中，`addOnShutterButtonListener()`方法实现如下：

```java
public void addOnShutterButtonListener(OnShutterButtonListener listener) {
    if (!mListeners.contains(listener)) {
        mListeners.add(listener);
    }
}
```

到这里，很自然的就想到，需要去找这个`mListeners`被什么地方调用了，那么我们在这个文件中搜索`mListeners`，看看在哪里被调用了
