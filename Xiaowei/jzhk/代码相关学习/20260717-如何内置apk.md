# 将apk放入源码路径

假设APK路径为：

```bash
SYS/vendor/sprd/platform/packages/apps/MyApp/MyApp.apk
```

# 编写mk文件

在目录`SYS/vendor/sprd/platform/packages/apps/MyApp/`下新建一个Android.mk文件，内容如下：

```makefile
LOCAL_PATH := $(call my-dir)
include $(CLEAR_VARS)

# 模块名（通常与 APK 包名或文件名一致，但不强制）
LOCAL_MODULE := MyApp

# APK 文件名（实际存在的 apk 文件）
LOCAL_SRC_FILES := $(LOCAL_MODULE).apk

# 模块标签：optional 表示所有版本都编译
LOCAL_MODULE_TAGS := optional

# 模块类型：APPS 表示这是一个应用
LOCAL_MODULE_CLASS := APPS

# 签名方式：
#   platform  → 使用系统签名（成为系统应用）
#   PRESIGNED → 保留原签名（APK 已签名）
LOCAL_CERTIFICATE := platform

# 预置位置：
#   true  → system/priv-app（拥有更高权限）
#   false → system/app
LOCAL_PRIVILEGED_MODULE := false

# 后缀（固定写法）
LOCAL_MODULE_SUFFIX := $(COMMON_ANDROID_PACKAGE_SUFFIX)

# 可选：强制不进行 dex 预优化（有时用于调试）
# LOCAL_DEX_PREOPT := false

include $(BUILD_PREBUILT)
```

# 将该APK添加到产品配置文件（Product.mk）中

找到项目的产品配置（Product.mk）文件，在这里面添加该APK模块。在该文件中找到 `PRODUCT_PACKAGES` 变量，把你的模块名加进去：

例如：

```makefile
PRODUCT_PACKAGES += MyApp
```

或者直接在文件末尾追加：

```makefile
PRODUCT_PACKAGES += \
    MyApp \
    privapp-permissions-com.example.myapp \
    default-permissions-com.example.myapp \
    myapp-sysconfig
```
