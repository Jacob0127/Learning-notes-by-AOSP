# 根据字符定位

首先，根据QS磁贴对应字符定位，这里我用模式这个磁贴来做示例。

![1](C:\Users\admin38\Desktop\问题集\文档图片存放路径\1.png)

根据字符资源搜索“未启用任何模式”，看看在哪里定义的。

## 命令

```bash
find . -name "strings.xml" -type f | xargs grep -rn "未启用任何模式"
```

## 结果

```bash
$ find SYS/ -name "strings.xml" -type f | xargs grep -rn "未启用任何模式"
SYS/frameworks/base/packages/SystemUI/res/values-zh-rCN/strings.xml:479:    <string name="zen_mode_active_modes" msgid="1625850411578488856">"{count,plural, =0{未启用任何模式}=1{已启用“{mode}”模式}other{已启用 # 个模式}}"</string>
```

可以看到这个字符资源的`name=zen_mode_active_modes`，那么根据字符资源搜索哪里用到了它

# 找到调用该字符的代码

## 命令

```bash
grep -rn "zen_mode_active_modes" --include="*.java" -o --include="*.kt" SYS/frameworks/base/packages/
```

## 结果

```bash
SYS/frameworks/base/packages/SystemUI/src/com/android/systemui/qs/tiles/impl/modes/ui/mapper/ModesTileMapper.kt:58:zen_mode_active_modes
```

说明这个字符只被`ModesTileMapper.kt`调用了，打开这个文件看看代码
